Both models have the same six tables (InstructorProfile, StudentProfile, Course, Enrollment, Lecture, QRCodeUpload). My models.py is simpler. Each table has only the fields the assignment asks for. The only constraint is that a student can't enroll in the same course twice. The LLM version (robot-models.py) is more complete, mostly because I asked it to focus on cheating. Its QR codes are random tokens that only work for 15 minutes and can be rotated, each upload stores a hash of the image and the student's IP address so a shared photo can be caught, and a student can have only one accepted check-in per lecture. The tradeoff is that it's harder to implement.  For this homework I'd keep my version and add the time-limited QR code and the one-check-in-per-lecture rule from the LLM version later.
